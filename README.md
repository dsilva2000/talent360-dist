# talent360-dist

Built copy of **Talent 360** as published at <https://mancolab.com/talent360/> (CareerScore and Prácticas), a project of Manco Lab.

- `talent360/` holds exactly the public files the site serves (HTML, CSS/JS, data JSON, the visit-counter endpoints and `.htaccess`). It contains no source code, no private data and no credentials. The stats report holds only a SHA-256 hash.
- The release `cpanel-latest` carries `talent360.tar.gz` and `talent360.tar.gz.sha256`, which the hosting server pulls.
- This repository is generated automatically. Please don't edit it by hand.
